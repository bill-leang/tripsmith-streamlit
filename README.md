An AI-powered travel planner that generates **personalized itineraries** with flights, hotels, and activities — all in one place.

🌍 [**Live Demo**](https://tripsmith-app-b5zxykaebxgy7qjhxa5vzl.streamlit.app/)
📂 [**GitHub Repo**](https://github.com/bill-leang/tripsmith-streamlit/)

---

## 🚀 Features

* 🧳 Create a **day-by-day travel itinerary**
* 🛫 Include **flights, hotels, and activities**
* 🎯 Specify:

  * Destination & origin
  * Travel dates
  * Budget
  * Number of travellers

---

## 🛠️ Tech Stack

* **Python**
* **Streamlit** – interactive web app
* **OpenAI** – LLM itinerary generation
* **Tavily API** – points of interest (POIs) & search
* **SerpAPI** – flight & hotel data
* **Requests / REST APIs** integration

---

## 📦 Installation

```bash
git clone https://github.com/bill-leang/tripsmith-streamlit.git
cd tripsmith-streamlit
python setup.py
# edit .env with your API keys for OpenAI, Tavily and Serpapi
streamlit run streamlit_app.py
```

---

## 💡 Usage

1. Enter your **origin, destination, dates, budget, and number of travellers**.
2. The AI generates a **personalized itinerary** with flights, hotels, and activities.
3. Browse your tailored travel plan in a simple Streamlit interface.
